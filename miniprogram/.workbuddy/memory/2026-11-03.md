## 新增「生产任务 + BOM 齐套分析」（本轮）

### 数据模型（store.js，schemaVersion 2）

- 物料复用商品表：新增 15 个机芯物料（id `M3001`–`M3015`，sku `MT-xxxx`），扩展分类为「机芯结构件 / 电机驱动 / 电子元件 / 线束辅料 + 原 4 类」。
- `boms`：`{ id, version, name, remark, items:[{goodsId,qty}] }`，种子 V3.1（15 项）、V3.0（10 项）。
- `tasks`：`{ id:T-YYYYMMDD-NN, bomId, version, planQty, doneQty, status, operator, createdAt }`，种子一条 V3.1 × 20。
- **存量数据迁移**：`loadState` 检测 `schemaVersion`，`migrateState` 补 boms/tasks + 按 sku 补物料，保留原记录与库存，不覆盖已有物料。

### 齐套计算（analyzeBom）

- need = qty × planQty；gap = need − stock；after = stock − need。
- 状态：`short`（gap>0，缺料）、`warn`（after ≤ safeStock，含正好用完）、`ok`。
- `maxAssemble = min(floor(stock / qty))`；`purchaseAmount` 按单价估算，**金额需 `Math.round(x*100)/100` 避免 0.12 元单价浮点噪声**。
- V3.1 × 20 台基准结果（测试断言值）：缺料 6 种、预警 2 种、充足 7 种、最多可做 4 台、采购 4122 元。
- 报工 `reportTask`：先整体校验，缺料整单拒绝，再批量扣料 + 生成一条 `typeText:'领料'` 的 out 记录（`detailText` 存领料明细）。

### 页面

- `pages/task/index`：任务卡（进度/三指标/提示）、筛选（全部/缺料/做完预警/充足）、采购单弹层（可复制）、报工弹层、新建任务弹层、切换任务。
- `pages/bom/index`：版本胶囊切换、物料增删改单台用量、粘贴导入（`物料编码 用量`，兼容 Excel 多列取首列+末列）、版本管理。
- 首页在 hero 下新增「当前任务」卡；`app.wxss` 新增通用 `.mask/.sheet` 弹层样式。

## 新增「分类管理」页（本轮，schemaVersion 3）

### 数据层（store.js）

- 分类从写死常量 `CATEGORIES` 改为可维护数据：`state.categories = [{ id:'C001', name }]`，种子 `SEED_CATEGORIES`（8 个原有 + 兜底「未分类」）。
- 兜底分类常量 `FALLBACK_CATEGORY = '未分类'`：不可删除、不可重命名，删除分类时其下商品默认迁到这里。
- 新 API：`listCategories()`（带 `goodsCount` / `removable`）、`categoryNames()`、`getDefaultCategory()`、`addCategory(name)`、`renameCategory(id,name)`（同步改商品）、`removeCategory(id,{moveTo})`。
- `saveGoods` 增加分类校验：分类不在表中则归到「未分类」。
- 迁移：`migrateState` 补 `categories`，并把商品里出现但表中没有的历史分类补进去；`resetDemoData` 恢复种子分类。
- 名称校验：空 / 重名 / 超过 12 字 / 使用「未分类」均拒绝。

### 页面

- 新增 `pages/category/index`：分类列表（名称 + 商品数 + 行内重命名/删除）、底部「＋ 新增分类」、新增/重命名共用底部弹层（`bindconfirm` 可直接保存）。
- 商品页：分类条改为「左侧横向滚动 + 右侧固定『分类管理』入口」（`.cat-bar` / `.cat-bar__scroll` / `.cat-bar__manage`）；`refresh()` 每次从 store 重取分类，当前筛选分类被删则回退「全部」。
